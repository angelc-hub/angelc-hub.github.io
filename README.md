# Portfolio — Jose Angel Condori Ccapa
Astro + TypeScript, 100% estático.

    npm install
    npm run dev        # desarrollo
    npm run build      # verifica tipos y genera /dist

- Edita todo el contenido en `src/data/portfolio.ts` (niveles, proyectos, LinkedIn, idiomas).
- Cambia `site` en `astro.config.mjs` y `robots.txt` por tu dominio.
- Si cambias datos del CV, actualiza `scripts/generate_cv.py` y ejecuta `npm run cv` (requiere reportlab).
- Versión imprimible alternativa: `/cv`.
